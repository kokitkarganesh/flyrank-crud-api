# Task API — FlyRank Backend Internship A3

A small FastAPI CRUD API backed by PostgreSQL and fully containerized with Docker Compose.

This project continues the previous CRUD assignments:

- A1: FastAPI CRUD API
- A2: SQLite persistence
- A3: PostgreSQL + Docker Compose

The API provides task creation, reading, updating, and deletion.

## Assignment Goal

The goal of A3 is to run the Task API against a real PostgreSQL database and start the complete application stack with one command:

```text
docker compose up
